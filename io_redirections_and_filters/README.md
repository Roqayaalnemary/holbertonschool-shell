0-hello_world: Prints Hello, World followed by a new line.
2-hellofile: Displays the contents of /etc/passwd.
3-twofiles: Displays the contents of /etc/passwd and /etc/hosts.
5-firstlines: Displays the first 10 lines of /etc/passwd.
6-third_line: Displays the third line of the file iacta.
8-cwd_state: Writes the output of ls -la to ls_cwd_content, overwriting the file if it exists.
9-duplicate_last_line: Duplicates the last line of the file iacta.
10-no_more_js: Deletes all regular .js files in the current directory and its subdirectories.
11-directories: Counts directories and subdirectories, including hidden directories, excluding the current directory.
12-newest_files: Displays the 10 newest entries in the current directory, from newest to oldest.
13-unique: Prints words that appear exactly once, sorted alphabetically.
14-findthatword: Displays lines containing root from /etc/passwd.
15-countthatword: Counts lines containing the pattern bin in /etc/passwd.
16-whatsnext: Displays lines containing root and the three lines after each match in /etc/passwd.
17-hidethisword: Displays lines in /etc/passwd that do not contain the pattern bin.
18-letteronly: Displays lines in /etc/ssh/sshd_config that start with an alphabetic character.
19-AZ: Replaces every A with Z and every c with e in the input.
20-hiago: Removes all lowercase c and uppercase C characters from input.
